A boxed block for one job, offer or status: a bold title with a status word on the right, a muted explanation, then small buttons.

**Use** `.job` for contracts, challenges, block events, heat and cred, and confirmation steps (import a backup). It replaces dialogs: the game never uses browser pop-ups.

**Tokens:** `panel` on `line`, radius `radius-md`, padding `space-10`/`space-12`, gap `space-4`. The status word takes the meaning color (`gold` reward, `ok` done or safe, `neon` danger) and a border may take it too for emphasis.
