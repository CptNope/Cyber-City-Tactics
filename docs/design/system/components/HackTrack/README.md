The lock-cracking track: a cursor sweeps across and the player hits while it is inside the green window.

**Use** `.trk` with `.zone` (left and width as percentages) and `.cur` (left as a percentage); set `data-f="ok"` or `data-f="bad"` for a 14-frame flash after a hit or a miss. Show progress below as filled and empty nodes (`ok`) and remaining misses (`neon` diamonds).

**Tokens:** ground `track`, border `line`, radius `radius-sm`; window `ok` at 28% with solid `ok` edges; cursor `neon` with `shadow-cursor`.
