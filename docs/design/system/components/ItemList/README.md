Rows of gear, NPC stock, perks or feats: name and description on the left, actions on the right.

**Use** `.list` > `.item`, with `.nm` (name) and `.ds` (one muted line) and `.acts` (small buttons). Item names take their rarity class: `.r0` Street (`rarity-street`), `.r1` Tuned (`mana`), `.r2` Prototype (`gold`), `.r3` Black-market (`legendary`). Comparisons use `.up` (`ok`, ▲) and `.down` (`neon`, ▼).

**Rule:** rarity is also in the name (*Tuned*, *Prototype*), so color is never the only cue.

**Tokens:** `panel` on `line`, radius `radius-md`, padding 9px/`space-12`, gap `space-10`; `small` text style for `.ds`.
