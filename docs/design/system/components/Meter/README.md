A thin progress bar for karma to the next level and legend rank.

**Use** `.meter` with an inner `i` whose width is the percentage. Always print the numbers next to it.

**Tokens:** track `meter-bg`, fill `karma`, 6px tall, radius `radius-xs`. In the canvas HUD the same idea draws HP (`neon`), mana (`mana`), karma (`karma`) and the special meter (`gold`), each with a `track` outline.
