Tabs switch between views of one screen: Codex sections, Character and Skills, skill trees, safehouse vendors.

**Use** a `.tabs` row of `.tab` buttons with `role="tab"` and `aria-selected`. A gold `.dot` marks a tab with something to do (points to spend).

**Controllers:** LB and RB cycle the tab group that holds focus, else the last group on the card.

**Tokens:** `tab` text style; unselected `muted`; selected `text` on `panel2` with a `line` border; underline `line`; dot `gold`; radius `radius-sm`.
