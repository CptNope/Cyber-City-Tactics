Big numbers with small labels: runner attributes on the character sheet and run stats on end screens.

**Use** `.attrs` > `.attr` (`.k` label, `.v` value with an optional `+1` button, `.h` hint) and `.stats` > `div` (`b` value, `span` label). Values use tabular figures so they don't jitter.

**Tokens:** value in the `stat` style (30px) or 26px for run stats, label in `label` style, `panel` on `line`, radius `radius-md`, grid gap `space-8`.
