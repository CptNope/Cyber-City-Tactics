A runner coat choice: the coat color and its accent split on the diagonal.

**Use** `.swatch` with `--c1` (coat) and `--c2` (accent); `.on` for the selected one (gold outline); `disabled` plus 🔒 for locked coats, with the unlocking feat in the title. Always give an `aria-label` with the coat's name.

**Tokens:** 26px square (32px on touch), radius `radius-sm`, border `line`, selected outline `gold`.
