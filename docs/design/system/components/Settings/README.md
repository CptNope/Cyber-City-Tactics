Settings rows: a name and optional hint on the left, a segmented control on the right.

**Use** `.setrow` and `.seg` with `aria-pressed` on each option. Two to four short options; anything longer becomes a button.

**Tokens:** selected option `neon` with `on-neon` label; others `muted`; dividers `line`; `tab` text style; minimum height 38px.
